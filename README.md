# MySQL Python Bookstore Project

This is a beginner database programming project using Python and MySQL.

## What the project does

- Connects Python to a MySQL database
- Creates and uses bookstore-related tables
- Inserts sample data
- Runs SQL queries involving publishers, authors, titles, and subjects
- Writes query results to an output text file

## Technologies used

- Python
- MySQL
- mysql-connector-python
- SQL

## Files

- `project2.py` - Main Python program
- `schema.sql` - Creates the database and tables
- `sample_data.sql` - Inserts sample starter data

## How to run

1. Create the database tables using `schema.sql`.
2. Insert the sample data using `sample_data.sql`.
3. Install the Python connector:

```bash
pip install mysql-connector-python
